# Medieval shop visuals

This folder contains only shop presentation assets. The original gameplay scenes,
button node paths, signal connections, defender art and balance are preserved.
`scripts/shop_visual.gd` reads prices from the existing defender scenes.

`medieval-frame-v1.png` was generated with the built-in ImageGen tool. It is an
opaque decorative background, with no baked-in UI text or controls. The original
generated file was copied here without editing. Nearest-neighbor filtering is
applied to the shop in `scenes/main.tscn`.

The editable SVG button frames, coin, divider and original Latin/Cyrillic bitmap
font are generated by `python assets/ui/shop/build_assets.py` (Python stdlib only).
Labels remain live Godot controls. Portraits use existing level-one game art,
with transparent margins cropped in memory; source images are unchanged.

The shop includes Knight, Archer, Wizard and Catapult. Catapult uses its existing
scene cost and placement rules. The right-edge tab and physical B key toggle a
0.24-second slide animation; the gold label moves with the panel while retaining
its original node path. Repeated toggles reverse from the current position. Tab
clicks are excluded from map placement, and hidden cards cannot retain focus.

Starting a round closes the drawer. The shop and its gold label draw at z=100,
above enemies, defenders and their effects; the pause CanvasLayer remains above
the shop. The pixel checkboxes control automatic rounds and 3x gameplay speed.
Auto-start begins the first/next wave after a one-second pause, can be cancelled,
and respects game pause and defeat. Speed resets when leaving the game scene;
the drawer animation and the auto-start delay ignore the speed multiplier.

The same theme styles defender upgrade/sell actions, framed tooltips and the
castle health bar. `pixel_health_bar.gd` keeps the existing ProgressBar value API
and draws its tiled fill inside the frame. The bitmap alphabet includes tooltip
parentheses and the percentage sign. Defeat screen art and its exact generation
prompt are stored in `assets/ui/defeat/`.

## ImageGen prompt (verbatim)

```text
Use case: stylized-concept
Asset type: production pixel-art game UI frame texture for a medieval tower-defense shop.
Generate ONE tall narrow ornamental panel, canvas 768 x 2048, the panel filling the entire canvas edge to edge. Straight-on, perfectly flat front view, no perspective. Aspect ratio 3:8.
Style: authentic hand-placed pixel art, hard square pixel clusters on a consistent low-resolution grid, designed as if originally 192 x 512 and enlarged exactly 4x nearest neighbor. No smooth gradients, no antialiasing, no glossy vector look.
Panel: nearly black blue-charcoal slate inset with very subtle sparse pixel texture, heavy double antique gold / bronze carved border with stepped chamfered corners and small gold rivets. Inner dark field starts at x 58 and ends at x 710. Border hugs the extreme left and right edges for the full height.
Decorative zones: at the top only (y 0 to 235), a modest golden medieval crest with a tiny fleur-de-lis, burgundy cloth folds tucked into upper corners, sparse ivy leaves over the upper border. At the bottom only (y 1740 to 2048), a small central gold fleur-de-lis with horizontal trim and a few tiny ivy leaves on outer corners. Keep every part between y 240 and y 1730 empty dark slate, completely unobstructed, for live UI controls. No internal cards, no internal dividers. Elegant restrained medieval craftsmanship, strong readable silhouette.
Palette: charcoal #141b22, deep brown #32291d, bronze #79502c, gold #c59a4a, pale gold #f2d48a, burgundy #6c2630, moss #526439.
Text: NONE. No letters, words, numbers, icons of coins, characters, weapons, buttons, scenery, drop shadow outside canvas, watermark or UI mockup. Only the empty reusable frame texture. Opaque background.
```
