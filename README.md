# 🏰 Tower Defense — 2D Game

Учебный проект 2D игры в жанре Tower Defense, разработанный на игровом движке Godot.

## 📖 О проекте

Игроку необходимо защищать замок от волн противников. Для защиты можно размещать боевых персонажей рядом с дорогой, по которой движутся враги.

Игрок получает золото за уничтожение противников и завершение раундов, после чего может использовать его для размещения и улучшения защитников.

Проект разработан в рамках учебной работы.

## 🎮 Основные механики

- 🏰 Защита замка от противников
- 👾 Волны врагов
- ⚔️ Размещение защитников на карте
- 🎯 Автоматический поиск цели
- 🔄 Поворот защитника в сторону выбранного врага
- 💰 Система золота
- 🏆 Награда за уничтожение врагов
- 🎲 Система раундов
- ❤️ Система здоровья замка
- 💀 Условие проигрыша при разрушении замка
- ⬆️ Система улучшения защитников
- 🛒 Покупка защитников
- 💵 Продажа защитников
- ❌ Отмена размещения защитника
- 📏 Проверка допустимого места для размещения
- 🔴🟢 Отображение возможности размещения защитника

## ⬆️ Система улучшений

Защитники имеют 3 уровня развития.

### Рыцарь

| Уровень | Урон | Радиус атаки | Перезарядка |
|--------:|-----:|-------------:|------------:|
| 1 | 20 | 100 | 1.0 сек |
| 2 | 35 | 120 | 0.9 сек |
| 3 | 55 | 140 | 0.75 сек |

Стоимость улучшений:

- 1 → 2 уровень — **50 золота**
- 2 → 3 уровень — **100 золота**

После достижения 3 уровня улучшение становится недоступным.

## 💰 Продажа защитников

Размещённого защитника можно продать, чтобы освободить место на карте.

Стоимость продажи составляет **50% от общей суммы золота, вложенной в защитника**.

## 🕹️ Управление

| Действие | Управление |

| Выбрать защитника | Левая кнопка мыши |
| Разместить защитника | Левая кнопка мыши |
| Отменить размещение | Правая кнопка мыши |
| Улучшить защитника | Кнопка в интерфейсе |
| Продать защитника | Кнопка в интерфейсе |
