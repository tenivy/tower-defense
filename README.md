# 🏰 Рыцари Конечной Станции

> Средневековый Tower Defense для тех, кто устал слушать объявления «Осторожно, двери закрываются».

Подземный город. Конечная станция. И ваша таверна-замок, которую каждую ночь пытаются разграбить гоблины, тролли и один очень настойчивый Король троллей.

Вы не герой. Вы — тот, кто держит оборону, пока весь остальной мир едет домой на последней вагонетке.

---

## 🎮 О чём игра

**Рыцари Конечной Станции** — компактный 2D Tower Defense в духе «поиграл пять минут в метро — и вернулся к жизни». Никаких открытых миров, никаких сюжетных твистов на три часа. Есть путь, есть волны, есть сетка, куда ты ставишь своих чудаковатых защитников, и есть замок с 20 HP, который ты изо всех сил пытаешься не потерять.

Сделано на **Godot 4** (рендерер Compatibility — летает даже на калькуляторе). Без платных ассетов, без интернета, без сохранений. Только чистый, честный рогалик-менеджмент обороны.

## ⚔️ Твои защитники

| Юнит | Цена | Роль | На максимуме умеет |
|------|------|------|--------------------|
| 🛡️ **Рыцарь** | 50 | Дёшево и сердито, ближний бой | Вихрь стали: бьёт до 3 врагов за удар |
| 🏹 **Лучник** | 100 | Универсал средней руки | Тройной залп огненными стрелами |
| 🔮 **Маг** | 250 | Ответ на бронированных гадов | Магическая буря: AoE + сильный слоу |
| 💥 **Катапульта** | 500 | Дорого, медленно, но со вкусом | Осадный залп: стан + огромный радиус |

Каждый защитник прокачивается **до 5 уровня**. Улучшения стоят прогрессивно дороже, но ощутимо сильнее — от «просто меч» до «вихрь, который решает исход волны». Продавать можно: вернётся 70% вложенного золота. Так что ошибаться не стыдно, стыдно не переставлять.

## 👹 Кто идёт на тебя

От мелочи до катастрофы:

- **Гоблин** — пушечное мясо, учит тебя считать монеты.
- **Скелет** — медленный, но в броне, лучнику уже потяжелее.
- **Волк** — быстрый, проскакивает мимо первых рядов, если не прикрыл фланг.
- **Орк** — живучий, любит стоять и получать по щам.
- **Тролль** — регенерирует, если его долго не бить. Не давайте ему передохнуть.
- **Упырь** — игнорирует замедление и половину магии. Магам больно, лучникам ок.
- **Огр** — ходячая стена брони. Только маг или катапульта.
- **👑 Король троллей (босс)** — призывает гоблинов прямо из-под себя, иммунен к стану и приходит ровно на 10-й волне. Финальный экзамен.

## 🌊 Как это играется

1. Стартовые **100 монет**, **20 HP** замка, пустая сетка и одна дорога.
2. Ставишь защитников на свободные клетки (зелёный призрак = можно, красный = туда нельзя).
3. Жмёшь **«Начать волну»** — и наблюдаешь, как средневековая нечисть ползёт к твоим воротам.
4. За убийства капают монеты → новые юниты и апгрейды между волнами.
5. Проходишь **10 волн** → победа. Потерял замок → «Замок пал», рестарт.

Один забег ≈ **5–10 минут**. Идеальный размер для одной поездки от дома до работы.

## 🕹️ Управление

Настроено под **одну руку** (потому что второй вы держитесь за поручень):

- Тап по магазину снизу → выбрать юнита.
- Тап по полю → поставить.
- Тап по уже стоящему юниту → панель улучшения/продажи.
- Крупная кнопка «Начать волну» → поехали.

На десктопе всё то же самое мышкой, плюс горячие клавиши дебага для разработчиков (см. ниже).

## 🛠️ Технологии

- **Движок:** Godot 4.x
- **Язык:** GDScript
- **Графика:** процедурные плейсхолдеры (квадраты, круги, цвета) — чтобы фокус был на геймплее, а не на поиске бесплатных спрайтов
- **Архитектура:** модульная, весь баланс вынесен в `Balance.gd` одним файлом — правь цифры и тестируй без переписывания логики

### Структура проекта
```
res://
├── project.godot        # точка входа, настройки рендера и окна
├── Balance.gd           # ВСЕ числа игры в одном месте
├── GameManager.gd       # монеты, HP, состояние боя
├── WaveManager.gd       # спавн 10 волн
├── Enemy.gd             # движение по пути, HP, статусы
├── Defender.gd          # поиск цели, атака, апгрейды
├── Projectile.gd        # снаряды, AoE, эффекты
├── UIController.gd      # магазин, панели, HUD
├── PathUtils.gd         # геометрия пути и проверка клеток
└── Main.gd              # сборка всего вместе
```

## ▶️ Как запустить

1. Установи [Godot 4](https://godotengine.org/download) (стандартная версия, не .NET).
2. Склонируй репозиторий:
   ```bash
   git clone git@github.com:<твой_логин>/2dGame.git
   ```
3. Открой `project.godot` в Godot → нажать **Play** (F5).

Готово. Интернет для игры не нужен.

Пока балансируешь, не хочется каждый раз проходить игру руками:

| Клавиша | Действие |
|---------|----------|
| `F1` | +100 монет |
| `F2` | убить всех врагов текущей волны |

| `F4` | +1 HP замку |
