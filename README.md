# 🏰 2D Tower Defense (Godot 4)

Учебный игровой проект на Godot 4: классический tower defense с волнами врагов,
свободной установкой защитников, экономикой и прогрессией раундов.

Главный приоритет проекта — аккуратная архитектура: универсальные скрипты
защитников и врагов, настройки типов через сцены, минимум дублирования кода.

Разрешение: 1280×720, игра рассчитана на один экран.

## Как запустить

1. Установите Godot 4.x.
2. Откройте проект (файл `project.godot`).
3. Нажмите F5 — запустится главная сцена.

## Управление

- ЛКМ по кнопке магазина — выбрать защитника для установки.
- ЛКМ по карте — поставить защитника (призрак подсвечивается зелёным/красным).
- ПКМ — отменить установку.
- ЛКМ по модели защитника — выбрать его (появятся панель и радиус атаки).
- Кнопки «Улучшить» / «Продать» — прогрессия и продажа выбранного защитника.
- Кнопка раунда — запустить очередную волну врагов.

## Игровой цикл

- Враги идут по дороге к замку волнами.
- Игрок за золото ставит защитников вне дороги.
- Защитники автоматически атакуют врагов в своём радиусе.
- Золото даётся за убийства и за завершение раунда.
- Дошедший до замка враг отнимает здоровье замка.
- При нулевом здоровье замка — поражение.

## Защитники

Универсальная система: вся боевая логика живёт в одном скрипте `Defender.gd`,
а каждый тип защитника — отдельная сцена с настройками через `@export`
(характеристики, массивы характеристик по уровням, цена, снаряд, анимации).
Новый тип защитника создаётся без копирования кода.

| Тип | Особенность |
| --- | --- |
| 🛡️ Рыцарь | Ближний бой, мгновенная атака, малый радиус |
| 🏹 Лучник | Дальняя атака стрелой-снарядом, большой радиус |

- 3 уровня улучшений: растут урон, радиус и скорость атаки.
- Прогрессивная цена улучшений (50 → 100 золота).
- Продажа возвращает половину вложенного (покупка + улучшения).
- Выбранный защитник показывает радиус атаки.
- Клик засчитывается по модели защитника; если модели пересеклись —
  выбирается ближайшая к точке клика.

## Враги

Универсальная система: скрипт `Enemy.gd` + сцены типов с `@export`-характеристиками
(скорость, здоровье, награда, урон по замку).

| Тип | Особенность |
| --- | --- |
| 👺 Гоблин | Быстрый, но слабый |
| 🐺 Оборотень | Медленный, живучий, сильно бьёт по замку |

- Движение по контрольным точкам дороги.
- Анимации ходьбы на 4 направления, переключение по направлению движения.
- Защитник выбирает цель с наибольшим **прогрессом по маршруту**
  (а не ближайшую по прямой) — корректно работает на извилистых дорогах.

## Снаряды

Стрела лучника — отдельная сцена `arrow.tscn` со скриптом `Arrow.gd`:
летит к цели с самонаведением, наносит урон при попадании, исчезает по истечении
дальности. Снаряды хранятся в отдельном контейнере `Projectiles`, чтобы не
пересекаться с логикой защитников.

## Анимации

- Защитники: `AnimatedSprite2D`, 12 анимаций (3 уровня × 4 направления).
- Враги: `AnimatedSprite2D`, 4 анимации ходьбы по направлениям.
- Направление выбирается по доминирующей оси вектора до цели (защитники)
  или вектора движения (враги).
- Флаг `mirrored_facing` поддерживает арт с зеркальной ориентацией кадров.
- В простое защитник стоит на выбранном статичном кадре (`idle_frame`),
  анимация играет только в бою.

## Структура проекта

res://
├── main.tscn главная сцена: карта, магазин, UI, раунды
├── Main.gd оркестрация игры: спавн, раунды, золото, установка и выбор
├── Defender.gd универсальный скрипт защитника
├── defender.tscn сцена Рыцаря
├── archer.tscn сцена Лучника
├── Enemy.gd универсальный скрипт врага
├── goblin.tscn сцена Гоблина
├── werewolf.tscn сцена Оборотня
├── arrow.tscn / Arrow.gd стрела лучника
└── sprites/ PNG-арт: кадры анимаций защитников, врагов, стрела

## Планы развития

- Волны врагов: смешивание типов врагов по раундам.
- Маг (урон по области) и Катапульта (осадный урон) на той же универсальной системе.
- Анимации атаки и смерти, эффекты попаданий.
- Балансировка характеристик.
